# 햄스터 노트 (웹앱)

햄스터 콩이가 메모를 볼주머니에 모아 두고, 회의를 받아 적어 중요한 것만 골라 메모장에 남겨 주는 핸드폰용 웹앱.

- 주소: https://jihyeonparkk1.github.io/hamster-note/ → Safari 공유 버튼 › "홈 화면에 추가"
- 메모·회의록은 이 기기 브라우저에만 저장 (백업 파일로 옮기기)
- 받아 적기: 기기 음성 인식(아이폰 Apple, 안드로이드 Google) / 정리: 기기 안에서 말투 규칙으로 골라내기 (AI·서버 없음)

이 폴더는 빌드 결과물입니다. 원본은 PC 앱 프로젝트의 `src/`·`web-src/`에서 `node tools/build-web.js`로 만듭니다.
